## 🔍 Overview

The **Santander Bootcamp 2023 – Data Science with Python** was originally run by DIO between August and October 2023. As a DIO Global Student, I have continuous access to the content and have been taking it at my own pace.

> 🚧 **So far this repository holds the Python fundamentals notebooks.** The bootcamp challenges listed below are not published here yet.

## 🚀 How to Use

1. **Browse online:** click any notebook; GitHub renders it with its outputs.
2. **Run locally:**

   ```bash
   git clone https://github.com/Laurentius96/DIO-Santander_DataScience.git
   cd DIO-Santander_DataScience
   pip install jupyter
   jupyter notebook
   ```

3. **Run in the cloud:** upload a notebook to [Google Colab](https://colab.research.google.com/) (File › Upload notebook).
